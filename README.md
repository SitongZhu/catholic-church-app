# Catholic Church Data Visualization App

An interactive web application for visualizing and analyzing global Catholic Church statistics. The app scrapes data from [Catholic-Hierarchy.org](https://www.catholic-hierarchy.org) and presents diocese-level statistics through interactive maps, charts, and tables.

## Features

- **Global-Level Visualization**: Interactive world map displaying the distribution of global Catholic statistics
- **Country-Level Analysis**: Filter and compare diocese data by country
- **Diocese-Level Details**: View detailed statistics and historical trends for individual dioceses
- **Time Series Analysis**: Historical data visualization from 1950-2025
- **Multiple Statistical Indicators**: Including Catholic population, clergy numbers, parish counts, and more
- **Data Processing Modes**: Support for viewing both raw data and statistically processed data

## Installation & Running

### Method 1: Using Docker

1. **Build Docker Image**
```bash
docker build -t catholic-church-app .
```

2. **Run Container**
```bash
docker run -p 3838:3838 catholic-church-app
```

3. **Access Application**
Open `http://localhost:3838` in your browser

### Method 2: Local Installation

#### Prerequisites
- R (>= 4.0)
- Python (>= 3.7)
- Required system libraries (see Dockerfile)

#### Installation Steps

1. **Install Python Dependencies**
```bash
pip install -r requirements.txt
```

2. **Install R Packages**
Run in R console:
```r
install.packages(c('shiny', 'dplyr', 'tidyr', 'readr', 'shinyWidgets', 
                   'ggplot2', 'DT', 'shinyjs', 'future', 'promises', 
                   'zoo', 'stringr', 'purrr', 'data.table', 'reticulate',
                   'leaflet', 'sf', 'rnaturalearth', 'rnaturalearthdata',
                   'shinydashboard'))
```

3. **Prepare Data**
Run the data processing script to generate `web_data.csv`:
```r
source("dc.R")
```

4. **Launch Application**
```r
shiny::runApp("web.R", port = 3838)
```

## Data Pipeline

1. **Data Collection** (`get_diocese_links.py`)
   - Fetches all diocese links from Catholic-Hierarchy.org
   - Generates `diocese_links_with_names.csv`

2. **Data Scraping** (`scrape_diocese.py`)
   - Scrapes detailed information for each diocese
   - Includes bishop information, statistics, general information, etc.
   - Generates `stats_with_bishop.csv`

3. **Data Processing** (`dc.R`)
   - Data cleaning and standardization
   - Time series interpolation
   - Handling duplicate diocese names
   - Generates final data file `web_data.csv`

4. **Data Visualization** (`web.R`)
   - Loads processed data
   - Provides interactive interface for data exploration

## Data Description

The application includes the following main statistical indicators:

- **Catholic Population**: Number of Catholics
- **Percentage of Catholics**: Percentage of Catholic population
- **Diocesan Priests**: Number of diocesan priests
- **Religious Priests**: Number of religious priests
- **Total Priests**: Total number of priests
- **Catholics per Priest**: Number of Catholics served per priest
- **Permanent Deacons**: Number of permanent deacons
- **Male Religious**: Number of male religious members
- **Female Religious**: Number of female religious members
- **Number of Parishes**: Number of parishes

Data Time Range: 1950-2025
- Pre-2010: Aggregated data every 10 years
- Post-2010: Annual data
